# Repos de referencia

Proyectos open source reales donde ver estos patrones aplicados en código, no solo en un tutorial.

- **[langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)** y sus [ejemplos oficiales](https://github.com/langchain-ai/langgraph-101) — buen punto de partida para ver orquestación con estado en código real.
- **[modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)** — implementaciones reales de MCP servers, para entender la estructura antes de escribir la propia.
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** — el propio repo del framework es un buen ejemplo de arquitectura de un sistema multi-agente en producción.

Si encontrás un repo que te sirvió como referencia real (no solo un tutorial), sumalo acá con una línea de contexto.
