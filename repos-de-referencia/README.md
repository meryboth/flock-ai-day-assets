# Repos de referencia

Proyectos open source reales donde ver estos patrones aplicados en código, no solo en un tutorial.

- **[langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)** y sus [ejemplos oficiales](https://github.com/langchain-ai/langgraph-101) — buen punto de partida para ver orquestación con estado en código real (ver `../orquestadores/`).
- **[modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)** — implementaciones reales de MCP servers, para entender la estructura antes de escribir la propia (ver `../mcp/`).
- **[crewAIInc/crewAI](https://github.com/crewAIInc/crewAI)** — el propio repo del framework es un buen ejemplo de arquitectura de un sistema multi-agente en producción (ver `../orquestadores/` y `../coordinacion-multiagente/`).
- **[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)** — un harness real, completo y open source, para leer de punta a punta (ver `../harness/` para la arquitectura explicada).
- **[500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)** — colección curada de 500+ proyectos de agentes de IA aplicados a industrias reales (salud, finanzas, retail, ciberseguridad y más), con implementaciones en distintos frameworks. Útil para encontrar un caso de uso parecido al tuyo antes de arrancar de cero.
- **[awesome_ai_agents](https://github.com/jim-schwoebel/awesome_ai_agents)** — un hub mucho más amplio (1500+ recursos): frameworks, herramientas, datasets, benchmarks y opciones de deployment. A diferencia del anterior (que es casos de uso por industria), este sirve más como punto de partida si todavía no sabés qué framework o herramienta usar.

Si encontrás un repo que te sirvió como referencia real (no solo un tutorial), sumalo acá con una línea de contexto.
