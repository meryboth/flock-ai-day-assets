# Cursos y charlas

Material formativo en video o curso para ir más en profundidad que un README — pensado para mirar antes o después del evento, no durante.

- **[Tips for building AI agents (Anthropic)](https://www.youtube.com/watch?v=LP5OCa20Zpg)** — Barry Zhang (Applied AI), Erik (Research) y Alex Albert (Claude Relations) charlando sobre qué funciona y qué errores comunes evitar al construir agentes.
- **[How AI agents & Claude skills work, Clearly Explained](https://www.youtube.com/watch?v=S_oN3vlzpMw)** (The Startup Ideas Podcast, con Ras Mic) — cómo funcionan las skills de Claude por dentro (qué se carga en contexto y cuándo) y una metodología concreta para construir una skill propia a partir de iterar sobre errores reales.
- **[Don't learn AI Agents without Learning these Fundamentals](https://www.youtube.com/watch?v=ZaPbP9DwBOE)** (KodeKloud) — tutorial largo y con labs prácticos que recorre todo el camino desde fundamentos de LLMs (tokens, embeddings, context window) hasta LangChain, RAG, LangGraph y MCP. Buen punto de partida si algún tema de la charla de Practitioner quedó corto.
- **[What AI Agent Skills Are and How They Work](https://www.youtube.com/watch?v=Lg-meK5IU8Q)** (IBM watsonx) — qué son las "skills" como módulos de conocimiento que un agente carga solo cuando hacen falta, en vez de meter todo en un prompt gigante.
- **[Intro to Agent Builder](https://www.youtube.com/watch?v=44eFf-tRiSg)** (OpenAI, Christina Huang — DevDay 2025) — herramienta visual de OpenAI para armar workflows agénticos sin empezar de cero en código; útil como contraste con el enfoque más "código primero" de LangGraph/CrewAI/Strands.
- **[Build Your Own AI Agent – Full Course with OpenAI, Langchain, Render Deployment](https://www.youtube.com/watch?v=MnG0ugK2JAI)** (freeCodeCamp.org, con Ania Kubow) — curso completo de 2 horas armando un Slackbot de producción de punta a punta (Node.js, OpenAI, LangChain, Postgres, deploy en Render con infra as code). Buen ejemplo de todo el recorrido, no solo el prompt.
