# Papers

Los papers detrás de los patrones que ya estás usando, para quien quiera ir a la fuente.

- **[ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629)** — el patrón base de "pensar, actuar, observar" detrás de casi todo agente con tools.
- **[Toolformer: Language Models Can Teach Themselves to Use Tools](https://arxiv.org/abs/2302.04761)** — cómo un modelo aprende cuándo y cómo llamar una herramienta.
- **[Reflexion: Language Agents with Verbal Reinforcement Learning](https://arxiv.org/abs/2303.11366)** — agentes que mejoran iterando sobre sus propios errores, sin reentrenar el modelo.
- **[Building Effective Agents (Anthropic)](https://www.anthropic.com/engineering/building-effective-agents)** — no es un paper académico, pero es la referencia más práctica y citada sobre cuándo un workflow simple le gana a un agente autónomo.
